# AI 知识库 — 项目愿景

## 概述

构建一个自动化的 AI 知识库系统，持续追踪 **GitHub Trending / Hacker News / arXiv** 等源头的 AI 相关内容，通过多 Agent 协作流水线完成 **采集 → 分析 → 整理 → 发布** 全流程，产出高质量、结构化的中文 AI 资讯与知识沉淀。

## 愿景

> 让 AI 领域的信息差趋近于零。  
> 每个开发者每天花 5 分钟，就能掌握 AI 世界正在发生什么。

## 目标用户

- **AI 开发者 / 研究人员** — 跟进前沿论文、开源项目、工具动态
- **技术决策者** — 了解行业趋势、生态变化、值得关注的方向
- **AI 学习者** — 获取结构化的学习路径和知识图谱

## 核心目标

1. **全自动** — 无需人工干预，Agent 自主完成从采集到发布
2. **高质量** — 去重、摘要、翻译、分类、评级，确保输出有价值
3. **结构化** — 知识以标准化格式沉淀，支持检索和关联
4. **时效性** — 追踪周期短于 24 小时，关键动态实时推送

## 系统架构

```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  Collector   │───▶│  Analyzer    │───▶│  Organizer  │
│  (采集 Agent) │    │  (分析 Agent) │    │  (整理 Agent) │
└─────────────┘    └──────────────┘    └─────────────┘
       │                   │                   │
       ▼                   ▼                   ▼
  GitHub Trending     摘要 & 翻译         分类 & 打标签
  Hacker News        技术深度分析        关联已有知识
  arXiv 论文         趋势判断 & 评级     生成发布内容
       │                   │                   │
       └───────────────────┼───────────────────┘
                           ▼
                    ┌──────────────┐
                    │  Publisher   │
                    │  (发布 Agent)  │
                    └──────────────┘
                           │
                           ▼
                    ┌──────────────────┐
                    │ 多渠道输出          │
                    │ 周刊 / 推送 / API   │
                    └──────────────────┘
```

### Agent 职责

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| **Collector** | 定时抓取各源数据，去重，结构化 | RSS / API / 爬虫 | 标准化条目 |
| **Analyzer** | 阅读原文，总结摘要，评估重要性 | 标准化条目 | 摘要 + 评级 + 技术分析 |
| **Organizer** | 归类、打标签、关联知识库 | 分析结果 | 结构化知识卡片 |
| **Publisher** | 按渠道格式化输出 | 知识卡片 | Markdown / JSON / 推送消息 |

## 技术栈

| 层 | 技术 |
|----|------|
| Agent 框架 | opencode / LangChain / 自定义 |
| LLM | GPT-4 / Claude / DeepSeek |
| 存储 | SQLite (本地) → PostgreSQL (生产) |
| 任务调度 | cron / Temporal / APScheduler |
| 发布渠道 | GitHub Pages / 微信公众号 / Telegram |

## 里程碑

| 阶段 | 目标 | 时间 |
|------|------|------|
| **P0 — 骨架** | Agent 框架搭建，单源采集 + 分析 MVP | 第 1 周 |
| **P1 — 闭环** | 三大数据源接入，完整流水线跑通 | 第 2 周 |
| **P2 — 质量** | 摘要优化、去重、评级、知识关联 | 第 3 周 |
| **P3 — 发布** | 周刊模板、多渠道输出、可视化 | 第 4 周 |

## 成功标准

- 日均处理 50+ 条 AI 相关内容
- 摘要准确率 > 90%（人工抽样评估）
- 从采集到发布延迟 < 30 分钟
- 用户阅读完成率 > 70%
